# Architecture decisions

This directory records consequential decisions for ci-workflows. Existing rationale remains in the linked technical/component guides; no numbered ADR has been invented during this documentation rollout.

For a new decision, use the next available `NNNN-<decision>.md` number and include status, context, decision, alternatives and consequences. Link the owning implementation and verification. A reversal creates a new record and marks the previous decision superseded. Domain definitions belong in [CONTEXT.md](../../CONTEXT.md).
